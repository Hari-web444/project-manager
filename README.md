# Project-manager Frontend

This is the frontend for the **Project-manager** application, built with **React** and **Vite**.
This is expects the WEB to run on **port 3000**.

It connects to the backend API, which must be running on **http://localhost:3001**.

## 🚀 Getting Started

### Prerequisites

- Node.js 
- npm or yarn

### Installation
npm i
npm run dev
