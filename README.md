# Project-manager API

This is a Node.js-based REST API for managing projects. It is designed to work in conjunction with the Project-manager frontend, which expects the API to run on **port 3001**.

## 🚀 Getting Started

### Prerequisites

- Node.JS
- npm or yarn i

### Installation

npm install

npm run dev
# or
yarn dev
⚠️ Important:
Make sure the API runs on port 3001 because the frontend is configured to connect to this port.
